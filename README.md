## 💻 Run Locally

To run this portfolio on your computer:

### 1. Clone the repository

```bash
git clone https://github.com/gobindagit2025/Portfolio.git
```

### 2. Open the project

```bash
cd Portfolio
```

### 3. Run the website

You can simply open:

```text
index.html
```

in your web browser.

Alternatively, you can use the **Live Server** extension in Visual Studio Code.

## 📤 Deployment

This portfolio is deployed using **GitHub Pages**.

Every time changes are pushed to the `main` branch, GitHub Pages can update the live website automatically.

```bash
git add .
git commit -m "Update portfolio"
git push origin main
```
